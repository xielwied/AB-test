# Анализ A/B-теста

Проект посвящён анализу влияния просмотра ленты новостей на то, насколько заранее студенты начинают выполнять задания до наступления дедлайна.

## Цель проекта

Сравнить поведение пользователей до и после просмотра ленты новостей и определить, могло ли это повлиять на время начала работы над заданиями.

## Используемые технологии

- Python
- Pandas
- SQLite
- SQL
- Jupyter Notebook

## Методика анализа

В рамках проекта:

1. Выполнено подключение к базе данных SQLite.
2. Данные об активности пользователей объединены с информацией о дедлайнах.
3. Наблюдения разделены на периоды `before` и `after`.
4. Рассчитана средняя разница между временем первого коммита и дедлайном.
5. Полученные значения сопоставлены для тестовой и контрольной групп.

В анализ включены только пользователи, представленные в обоих периодах. Данные по `project1` исключены.

Чем более отрицательное значение полученной разницы, тем раньше пользователь начал работу относительно дедлайна.

## Результаты

| Группа | До | После | Изменение |
|---|---:|---:|---:|
| Тестовая | −66,05 часа | −99,52 часа | −33,48 часа |
| Контрольная | −98,03 часа | −99,32 часа | −1,29 часа |

После просмотра ленты новостей участники тестовой группы начали работать приблизительно на **33,5 часа раньше**. В контрольной группе заметного изменения не произошло.

## Вывод

Полученные результаты поддерживают гипотезу о том, что просмотр ленты новостей может мотивировать студентов раньше начинать работу над заданиями.

Анализ является упрощённым. Для более строгого подтверждения причинно-следственной связи необходимо дополнительно провести проверку статистической значимости и рассчитать доверительные интервалы.
